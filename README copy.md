# MSME Vendor Payment Management System (Backend)

##  Overview
This project is a **backend API system** built using **NestJS, TypeScript, and PostgreSQL** to help MSMEs manage:
- Vendors
- Purchase Orders
- Payments
- Outstanding balances

The system focuses on **clean API design**, **correct business logic**, and **data integrity**.

---

## Tech Stack
- **Backend Framework:** NestJS
- **Language:** TypeScript
- **Database:** PostgreSQL
- **ORM:** TypeORM
- **Validation:** class-validator
- **API Testing:** Postman

---
